🩸 Blood In Need

Blood In Need is a web-based application designed to help people quickly find blood donors during medical emergencies. The goal of this project is to use technology for social good by reducing delays in connecting donors with those in urgent need.

🚀 Purpose

In critical situations, time matters. This application aims to simplify donor discovery, request management, and communication, making the process faster and more reliable.

🛠 Tech Stack
	•	Backend: ASP.NET (.NET)
	•	Database: SQL Server
	•	Architecture: Layered architecture (Controllers, Services, Data Access)
	•	Authentication: Secure user login and role-based access
	•	Other: Email notifications (with scope for SMS integration)

✨ Key Features
	•	User registration and secure authentication
	•	Blood request creation and management
	•	Donor data storage and matching logic
	•	Clean separation of business logic and data access
	•	Scalable design suitable for future enhancements

📂 Where to Look
	•	Controllers: Request handling and API logic
	•	Service Layer: Core business rules and workflows
	•	Data Access Layer: Database operations and SQL integration

⚠️ Note

This is a personal project built for learning and social impact. All data used is dummy/sample data only.
